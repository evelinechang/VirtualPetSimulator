# Virtual Pet Simulator

This is a C++ virtual pet simulator game.

## Description

The player takes care of a virtual pet by feeding it, playing with it, cleaning it, talking to it, letting it sleep, and taking it to the doctor.

The pet has four main stats:

- Age
- Hunger
- Happiness
- Cleanliness

The goal is to keep the pet healthy and happy until it reaches old age.

## Features

- Feed the pet with different food options
- Play with the pet using different activities
- Clean the pet using different cleaning options
- Talk to the pet to check its current stats and mood
- Sleep feature
- Doctor feature
- Money system
- Game over conditions
